Simready Tools

Единая профессиональная среда для сборки сцен, наполнения интерьеров и физической расстановки объектов в 3ds Max. Семь модулей покрывают весь пайплайн — от рисования объектами по поверхностям до физического сброса кучи товаров в контейнер.

⬇ Скачать скрипт (.MS) ⬇ tyFlow для Max 2022 (.DLO) ▶ Видеоурок

Модули:

🎨 Object Painter

Интерактивное рисование 3D-ассетами по любой поверхности с рандомизацией поворота и смещения. Поддержка иерархий, автоудаление исходников и быстрый поворот последнего объекта на 90°.

Интерактив

🔄 Replacer

Пакетная замена прокси-объектов финальными моделями с сохранением позиции, поворота и иерархии. Модели, стоящие на заменяемом объекте, сохраняются.

Пакетно

🌿 Scatter

Случайное распределение объектов по поверхностям с помощью лучей. Настройки масштаба, поворота и выравнивания по нормали.

Автоматически

📦 Shelf Tool

Автоматическая раскладка товаров на полках сеткой с расчётом размеров и зазоров. Многоуровневые шкафы и интерактивный Jitter.

Интерактив

📚 Book Shelf

Ставит книги, папки и органайзеры вертикально и заполняет каждую секцию полки вплотную, корешками в комнату.

Автоматически

📊 PolyCount

Анализ полигональной нагрузки с сортировкой по весу. Быстрый поиск тяжёлых объектов для оптимизации сцены.

Аналитика

💥 Physics Drop

Сбрасывает кучу моделей в контейнер или на поверхность с физикой tyFlow PhysX и ставит настоящие копии моделей в позиции, где они остановились.

Симуляция
ℹ️ Окна модулей: В главном окне есть кнопка для каждого модуля. Кнопка открывает модуль в отдельном окне, повторное нажатие его закрывает. При закрытии главного окна закрываются все окна модулей.

⚙️ Установка и запуск

Как установить и запустить Simready Tools в 3ds Max

Способ 1: Drag & Drop (быстро)

Шаг 1

Перетащите файл

Перетащите файл SimreadyTools.ms прямо во вьюпорт 3ds Max. Скрипт автоматически зарегистрируется как макроскрипт.

Шаг 2

Назначьте клавишу или кнопку

Откройте Customize → Customize User Interface. В списке Category найдите PHYSICL, выберите SimreadyTools и назначьте горячую клавишу или перетащите его на панель инструментов.

Способ 2: Scripting → Run Script

Шаг 1

Запустите скрипт

Откройте Scripting → Run Script... и выберите файл SimreadyTools.ms. Это зарегистрирует макроскрипт. Затем запустите его из категории PHYSICL, как в способе 1.

Требования

tyFlow

Нужен только для Physics Drop

Модуль Physics Drop работает на бесплатном плагине tyFlow. Без него все остальные модули работают, а Physics Drop сообщит, что tyFlow не установлен.

Для 3ds Max 2022: скачайте tyFlow_2022.dlo, закройте 3ds Max, скопируйте файл в папку Plugins установки 3ds Max (например, C:\Program Files\Autodesk\3ds Max 2022\Plugins) и снова запустите Max.

💡 Этот файл работает только в 3ds Max 2022. Для других версий Max нужна сборка tyFlow под соответствующую версию.
⚠️ Категория изменилась: С версии v2.9 инструмент находится в категории PHYSICL (раньше была Nfinite). Старые кнопки из категории Nfinite продолжают работать и открывают текущую версию. Но всё равно перетащите кнопку заново из PHYSICL: старый алиас удалят в одной из следующих версий.

🎨 Object Painter

Интерактивное рисование 3D-ассетами по поверхностям — как кисть, только объектами

1. Paint With — источник объектов

Source: Selected / List

Откуда берутся объекты

Selected — кисть рисует тем, что выделено во вьюпорте в момент нажатия START PAINTING. Удобно для быстрой работы с 1–2 объектами.

List (по умолчанию) — объекты загружаются в таблицу Items кнопкой [+]. Можно заранее подготовить набор и менять его без перезапуска.

Pick: Order / Random

Порядок выбора

Order — объекты из списка выдаются строго по очереди (1→2→3→1→2→3...). Идеально для ритмичной расстановки (скамейки, фонари).

Random — каждый клик кистью берёт случайный объект из списка. Идеально для органичного наполнения (книги, декор, мусор).

Mode: All / Selected

Активный фильтр

All — кисть использует все объекты из списка Items.

Selected — в рисовании участвуют только выделенные строки таблицы Items. Выделение строк можно менять прямо во время рисования.

Items: + / - / X / Sel

Управление списком

[+] — добавить выделенные объекты. [−] — удалить выделенные строки. [X] — очистить весь список. [Sel] — выделить объекты из списка во вьюпорте.

💡 [+] добавляет модели целиком, а не их части. Для модели внутри иерархии AutoLink берётся узел сразу под хелпером *_POS. Для остальных объектов берётся самый верхний родитель.

2. Paint On — целевые поверхности

Target: Grid / Scene / List

Где рисовать

Grid — объекты ставятся на конструкционную сетку. Scene — кисть работает по любому объекту сцены. List (по умолчанию) — рисование только по объектам из списка Surfaces.

Elem Only

Режим элементов

Кисть рисует только по выделенным полигонам. Выделите полигоны полки → включите Elem Only → рисуйте только по этой полке, игнорируя корпус шкафа и другие поверхности. Работает с Editable Poly и Editable Mesh и только при Target: List.

💡 Перед включением Elem Only выделите нужные полигоны на целевом объекте. Инструмент создаёт временную красную копию этих полигонов, рисует по ней и удаляет её по окончании.

3. Settings — параметры кисти

Spacing

Шаг кисти

Минимальное расстояние между объектами при рисовании штрихом, в единицах сцены. По умолчанию 50: объекты ставятся вдоль штриха не ближе 50 единиц друг к другу.

Offset

Смещение по нормали

Поднимает или утапливает объект относительно поверхности. Положительные значения — объект висит над поверхностью, отрицательные — входит в неё.

Follow

По направлению штриха

Объект разворачивается по направлению движения кисти. Идеально для расстановки вдоль пути.

Align / Z-Up / Flip

Ориентация

Align — выравнивание по нормали поверхности (объект следует наклону).

Z-Up (включён по умолчанию) — объект всегда стоит вертикально, даже на наклонных поверхностях.

Flip (Spot) — перевернуть объект (удобно для потолочных светильников).

Auto-Delete Sources

Автоудаление

Включено по умолчанию. После окончания рисования исходные объекты удаляются. Сцена остаётся чистой, без дубликатов.

Turn 90 (Last)

Быстрый поворот на 90°

Во время рисования поворачивает последний поставленный объект на +90° вокруг его локальной оси Z. Вне рисования поворачивает текущее выделение. Нажмите ещё раз — ещё 90°. Действие можно отменить.

4. Randomizer — хаос и естественность

X / Y / Z (Position)

Случайное смещение

Добавляет случайное смещение позиции при каждом клике. Значение — максимальное смещение в единицах сцены.

Rot X / Rot Y / Rot Z

Случайный поворот

Включает случайный поворот вокруг соответствующей оси (0°–360°). Rot Z — самая важная кнопка: поворачивает объект вокруг вертикальной оси, и расстановка выглядит естественно.

💡 Для естественного вида обычно достаточно только Rot Z. Rot X/Y добавляйте только для хаотичных сцен (обломки, мусор).
Reset Randomizer

Сброс

Обнуляет все смещения и выключает все кнопки Rot.

5. Прогресс и управление

Progress Label

Счётчик

Показывает «Placed: N / Total» в реальном времени. Когда все объекты расставлены, появляется «ALL OBJECTS PLACED!».

START PAINTING

Старт/стоп

Кнопка-переключатель. Нажмите — кисть активна, кликайте по поверхностям. Нажмите ещё раз (STOP PAINTING) или Escape — рисование завершится, временные группы распадутся, исходные имена восстановятся.

💡 Нарисованные копии исходника, который уже находится внутри иерархии *_POS, выносятся в корень сцены. Так они не скапливаются под одним POS, и их можно заново связать через Create Hierarchy. Закрытие окна во время рисования тоже корректно всё убирает.

📋 Порядок работы: Object Painter

1. Подготовьте ассеты в сцене (модели товаров, декор и т.д.).
2. Выберите Source: List и добавьте модели в Items кнопкой [+].
3. Выберите Target: List и добавьте целевые поверхности (полки, пол, стол).
4. Настройте Spacing (шаг) и Pick: Random для естественного вида.
5. Включите Rot Z в Randomizer для случайного поворота.
6. Нажмите START PAINTING и кликайте/ведите по поверхностям. Если объект встал не той стороной — Turn 90 (Last).
7. Нажмите STOP PAINTING или Escape, чтобы закончить.

🔄 Replacer

Пакетная замена прокси-объектов финальными моделями с сохранением позиции и иерархии

Replacement Sources — новые модели

New Models List

Список замены

Добавьте финальные модели, которыми будут заменены прокси. Кнопки [+] [−] [X] [Sel] — стандартное управление списком.

Pick Mode: Random / Order

Режим выбора

Random — каждая прокси заменяется случайной моделью из списка. Отлично для разнообразия.

Order — модели назначаются по очереди по кругу (1→2→3→1→2→3...).

Targets to Replace — что заменять

Existing Models List

Прокси для замены

Добавьте объекты, которые нужно заменить. Каждый удаляется вместе со своей иерархией, а на его месте появляется копия модели из Sources с тем же трансформом и родителем. Имена частей копии остаются чистыми (без суффиксов _001).

START REPLACEMENT

Выполнить замену

Заменяет все цели за один шаг, который отменяется одним Undo. По окончании показывается сводка.

💡 Модели, стоящие на или внутри заменяемого объекта (их собственные иерархии *_POS, например коробки на тележке), не удаляются. Они переносятся на новую модель и остаются ровно на своих местах. В сводке указано, сколько их сохранено.

📋 Порядок работы: Replacer

1. Расставьте простые прокси-боксы в нужных местах сцены.
2. Подготовьте финальные модели и добавьте их в Replacement Sources.
3. Выделите все прокси и добавьте их в Targets to Replace.
4. Выберите Random для разнообразия или Order для последовательности.
5. Нажмите START REPLACEMENT.

🌿 Scatter

Случайное распределение объектов по поверхностям с помощью лучей

Objects to Scatter — что разбрасывать

Items List

Объекты для разброса

Добавьте модели (трава, камни, мусор и т.д.). При разбросе случайный объект из списка клонируется как Instance (экономия памяти).

Surfaces — целевые поверхности

Target Surfaces List

Куда разбрасывать

Поверхности, на которые будут разбросаны объекты. Лучи пускаются сверху вниз в пределах общего габарита всех поверхностей; если поверхности перекрываются, берётся самое высокое попадание.

Settings

Count

Количество

Сколько объектов разместить (1–5000, по умолчанию 50). Для каждого объекта делается до 20 попыток найти подходящую точку.

Z Offset

Смещение по высоте

Поднимает или утапливает объекты по их локальной оси Z (от −100 до 100 единиц сцены). Удобно для камней — небольшое отрицательное значение частично закапывает их.

Align to Normal

По нормали поверхности

Включено по умолчанию. Объекты следуют наклону поверхности (для холмов). Если выключено, объекты всегда стоят вертикально.

Random Z Rot

Случайный поворот

Включено по умолчанию. Каждый клон поворачивается на случайный угол 0°–360° вокруг своей оси Z.

Scale Min / Max

Диапазон масштаба

Случайный равномерный масштаб в процентах (10–500, 100 = исходный размер). Пример: Min 80, Max 120 = от 80% до 120% исходного размера.

📋 Порядок работы: Scatter

1. Создайте поверхность ландшафта (Plane, меш рельефа).
2. Подготовьте объекты (камни, кусты) и добавьте их в Items.
3. Добавьте ландшафт в Surfaces.
4. Установите Count: 200, включите Align to Normal и Random Z Rot.
5. Установите Scale Min: 80, Max: 130 для разнообразия.
6. Нажмите START SCATTER. По окончании новые объекты будут выделены.

📦 Shelf Tool

Автоматическая раскладка товаров на полках с расчётом размеров, зазоров и интерактивным Jitter

1. Placement Targets — полки

Targets List

Список полок

Добавьте один или несколько объектов-полок. Инструмент обрабатывает каждую полку по очереди. Поддерживаются Editable Poly/Mesh.

Fill All Levels

Автопоиск уровней

Сканирует шкаф лучами и находит все горизонтальные поверхности (полки) внутри. Каждый уровень заполняется отдельно. Если выключено, заполняется только верхняя поверхность в центре объекта.

Elem Only

Режим элементов

Заполнять только выделенные полигоны. Выделите полигоны конкретной полки → объекты встанут только туда.

2. Objects to Array — товары

Items List

Объекты для раскладки

Добавьте модели товаров. Кнопки ▲ / ▼ сортируют их по площади основания (от меньшего к большему и наоборот).

Pattern: Order / Random

Порядок раскладки

Order — строгая последовательность (A-B-C-A-B-C). Random — случайный товар в каждую ячейку.

3. Array Settings — сетка

Cols (X) / Rows (Y)

Колонки и ряды

Размер сетки (по умолчанию 5 × 1). Cols — по ширине полки, Rows — в глубину.

Calculate X / Y

Авторасчёт

Вычисляет, сколько объектов поместится на первую полку из Targets, исходя из размера первого объекта в Items и значения Gap.

Depth (Z)

Штабелирование

Количество слоёв объектов друг на друге. Depth=2 — два слоя.

Gap (cm)

Зазор между объектами

Расстояние между объектами в единицах сцены. По умолчанию 30 (30 мм в сцене в миллиметрах). Увеличьте для свободной выкладки, уменьшите для плотной.

4. Рандомизация и ориентация

Pos Jitter / Rot Jitter

Интерактивный Jitter

По умолчанию 0.1 и 2°. Применяется в реальном времени к объектам последнего заполнения. Меняете значения — объекты сразу сдвигаются/поворачиваются. У каждого объекта своё зерно случайности, поэтому одно и то же значение всегда даёт один и тот же результат.

+90° / -90° / 180°

Быстрый поворот

Поворачивает каждый объект последнего заполнения вокруг его собственной оси Z на 90° или 180°. Используйте, если после Fill Shelf товары стоят боком.

5. Действия

FILL SHELF

Заполнить полку

Создаёт сетку клонов (Instance) на каждой целевой полке. Объекты центрируются на полке и распределяются по сетке. Имена частей клонов остаются чистыми. Полка, горизонтальная с точностью до 0.8°, считается идеально ровной, поэтому длинные ряды не «уползают» вверх или вниз.

UNDO

Отменить заполнение

Удаляет все объекты последнего заполнения. Повторное нажатие вызывает стандартный Undo 3ds Max.

📋 Порядок работы: Shelf Tool

1. Выделите шкаф/полку и добавьте в Targets кнопкой [+].
2. Добавьте модели товаров в Items.
3. Задайте Gap и нажмите Calculate X и Calculate Y.
4. Включите Fill All Levels, если нужно заполнить весь шкаф.
5. Нажмите FILL SHELF.
6. Если товары стоят боком — +90° или -90°.
7. Подкрутите Pos Jitter и Rot Jitter для естественного вида.

📚 Book Shelf

Ставит книги, папки и органайзеры вертикально и заполняет каждую секцию полки корешками наружу

ℹ️ Отличие от Shelf Tool: Shelf Tool раскладывает объекты сеткой. Book Shelf строит один ряд в каждой секции. Он сам ставит каждый объект вертикально, измеряет его реальную толщину и ставит объекты вплотную, пока секция не заполнится. Количество колонок задавать не нужно.

1. Placement Targets — полки

Targets List

Целевые полки

Добавьте один или несколько объектов-полок или шкафов. Поддерживаются Editable Poly/Mesh.

Fill All Levels

Все полки шкафа

Находит все горизонтальные полки внутри шкафа и заполняет каждую. Внешняя крышка шкафа пропускается автоматически, даже если верхняя панель — отдельный меш той же модели.

Elem Only

Только выделенные полигоны

Заполнять только те полки, полигоны которых выделены на целевом объекте.

2. Objects to Array — книги

Items List

Что ставить

Добавьте модели книг, папок или органайзеров. ▲ / ▼ сортируют их по площади основания.

Pattern: Order / Random

Последовательность

Order — объекты идут по порядку списка. Random — случайный объект на каждое место.

3. Spacing и Orientation

Gap (cm)

Зазор между книгами

Расстояние между соседними книгами в единицах сцены. 0 — вплотную. По умолчанию 30.

+90° / -90° / 180°

Быстрый поворот

Поворачивает каждую книгу последнего заполнения вокруг её собственной оси Z.

4. Что происходит при FILL SHELF

Вертикально

Автоориентация

Каждая книга поворачивается так, чтобы самая длинная сторона смотрела вверх, самая тонкая шла вдоль полки, а средняя — в глубину полки.

Направление ряда

Вдоль длинной стороны

Ряд идёт вдоль более длинной горизонтальной стороны полки. Шкаф, повёрнутый на 90°, всё равно заполняется по ширине.

Корешками наружу

Лицом в комнату

Инструмент находит открытую сторону полки (противоположную задней стенке) и разворачивает каждую книгу передним краем/корешком (там, где её хелпер) наружу.

Секции

Учитывает перегородки

Каждая полка делится на секции между боковыми стенками и перегородками, и каждая секция заполняется отдельно. Книги не встают поперёк перегородки.

Посадка

Точно на полку

Каждая книга центрируется по глубине полки и ставится ровно на её поверхность: не висит в воздухе и не проваливается в неё.

UNDO

Отменить заполнение

Удаляет все книги последнего заполнения вместе с их иерархиями. Повторное нажатие вызывает стандартный Undo 3ds Max.

📋 Порядок работы: Book Shelf

1. Добавьте книжный шкаф или стеллаж в Targets.
2. Добавьте модели книг/папок в Items.
3. Включите Fill All Levels (или выделите полигоны полки и используйте Elem Only).
4. Задайте Gap (0 — плотный ряд).
5. Нажмите FILL SHELF. Если всё заполнение смотрит не туда — 180°.

📊 PolyCount

Аудит полигональной нагрузки сцены — быстро найти самые тяжёлые модели

Параметры

Scope: Selected / Scene

Область анализа

Selected — только выделенные объекты. Scene — все объекты сцены. При переключении список обновляется.

REFRESH LIST

Обновить

Пересчитывает полигоны и сортирует список от самых тяжёлых к лёгким. Формат: «Полигоны | Имя объекта». Список также обновляется при открытии окна.

Object List

Интерактивный выбор

Клик по строке — объект выделяется во вьюпорте. Поддерживается множественный выбор. Удобно для быстрого перехода к проблемным объектам.

💡 Совет: Запускайте PolyCount после Scatter/Painter, чтобы проверить, не перегружена ли сцена тяжёлыми моделями. Объекты с 50 000+ полигонов стоит оптимизировать.

💥 Physics Drop

Сброс кучи моделей в контейнер или на поверхность с физикой tyFlow

⚠️ Заменяет MassFX Tools: Старый модуль MassFX удалён. Для Physics Drop нужен бесплатный плагин tyFlow. Модуль не добавляет физические модификаторы на ваши модели: он симулирует простые заменители и ставит настоящие копии моделей туда, где заменители остановились.

1. Models to scatter

Models

Что падает

Добавьте модели для сброса. Каждый выделенный объект приводится ко всей модели, поэтому можно кликнуть по любой её части. Составные модели падают как одно целое.

2. Container / surface

Colliders

Куда падают

Добавьте банку, корзину, ящик, полку или пол, куда должны упасть модели. Если добавить группу или хелпер, добавятся меши внутри неё.

Birth area

Откуда появляются объекты (необязательно)

По умолчанию объекты появляются над коллайдерами из области в половину размера контейнера по центру. Можно выбрать свой объект (например, плоскость, наклонённую под наклонную полку), чтобы все объекты падали с одинаковой высоты. clear возвращает автоматическую область.

💡 Делайте свою область заметно меньше проёма (примерно вдвое). Объекты, появившиеся над краем, скатываются и теряются. Сам наклон не мешает.

3. Settings

Count

Сколько

Количество объектов (1–2000, по умолчанию 24). Больше 250 — появится запрос подтверждения, потому что симуляция может занять минуты.

Gap

Зазор

Расстояние между соседями (по умолчанию 3 единицы сцены). Симулируемые заменители раздуваются на Gap/2, финальные модели — нет.

Frames

Время на успокоение

Сколько кадров даётся куче, чтобы улечься (30–900, по умолчанию 120). Увеличьте, если в статусе много пропущенных объектов.

Seed

Вариация

Измените, чтобы получить другую кучу при тех же настройках.

Helper size

Размер хелперов на моделях

30 — для мелочи (виноград, кофейные зёрна), 50 (по умолчанию) — для средних (помидоры, чашки), 200 — для крупных (арбузы). Слишком маленький хелпер прячется внутри меша; слишком большие перекрывают друг друга, и нужный не выделить.

4. Управление

DROP & BAKE

Запуск

Строит симуляцию, проигрывает её и ставит копию нужной модели на место каждого остановившегося объекта (геометрия — инстансами, хелперы — копиями). Объекты, которые к концу ещё двигаются, пропускаются. Всё временное удаляется, настройки таймлайна и воспроизведения восстанавливаются. Esc прерывает; тогда ничего не ставится.

RESET

Убрать последний сброс

Удаляет всё, что поставил последний DROP & BAKE, и только это; предыдущие сбросы остаются.

Строка статуса

Результат

После запуска показывает «Placed N, skipped M (время)».

📋 Порядок работы: Physics Drop

1. Добавьте модели в Models to scatter.
2. Добавьте контейнер или поверхность в Colliders.
3. При необходимости выберите свою Birth area для наклонных полок.
4. Задайте Count, Gap и Helper size.
5. Нажмите DROP & BAKE и дождитесь строки статуса.
6. Не нравится? RESET, поменяйте Seed или Frames и запустите снова.

📋 Примеры рабочих процессов

Типовые сценарии использования Simready Tools от начала до конца

🏪 Сценарий 1: Наполнение магазинного стеллажа

1. Импортируйте модель шкафа/стеллажа в сцену.
2. Откройте Shelf Tool → добавьте стеллаж в Targets.
3. Импортируйте модели товаров → добавьте их в Items.
4. Включите Fill All Levels, чтобы заполнить все полки.
5. Нажмите Calculate X/Y → FILL SHELF.
6. При необходимости поверните товары через +90°/-90°.
7. Добавьте Pos Jitter: 0.3 и Rot Jitter: 3 для реализма.
8. Используйте Object Painter (Elem Only) для ручной доводки отдельных полок.

📚 Сценарий 2: Книжный шкаф или архивный стеллаж

1. Откройте Book Shelf → добавьте шкаф в Targets.
2. Добавьте несколько моделей книг/папок в Items, выберите Random.
3. Включите Fill All Levels, задайте Gap: 0 для плотного ряда.
4. Нажмите FILL SHELF — все секции заполнятся, корешками наружу.
5. Уберите несколько книг вручную, чтобы шкаф выглядел «живым».

🍎 Сценарий 3: Куча в контейнере (Physics Drop)

1. Поставьте контейнер (миску, банку, ящик) в сцену.
2. Откройте Physics Drop → добавьте модели фруктов/товаров в Models.
3. Добавьте контейнер в Colliders.
4. Задайте Count и подходящий Helper size (30 / 50 / 200).
5. DROP & BAKE. Если объекты пропущены — увеличьте Frames и повторите.

🔄 Сценарий 4: Замена прокси на финальные модели

1. Расставьте простые прокси-боксы на полках через Shelf Tool или Painter.
2. Импортируйте финальные высокополигональные модели.
3. Откройте Replacer → добавьте финальные модели в Sources.
4. Выделите все прокси → добавьте их в Targets.
5. Выберите Random → START REPLACEMENT.
6. Проверьте результат через PolyCount — убедитесь, что сцена не перегружена.

❓ FAQ — частые вопросы

Решения типичных проблем

Частые вопросы

Вопрос

Painter не рисует — пустые клики

Убедитесь, что выбран Target: List и поверхности добавлены. Если включён Elem Only, полигоны на целевом объекте должны быть выделены заранее.

Вопрос

Shelf Tool ставит объекты боком

Нажмите +90° или -90° после FILL SHELF. Поворот сразу применяется ко всему массиву.

Вопрос

Physics Drop пишет «tyFlow is not installed»

Установите бесплатный плагин tyFlow для вашей версии 3ds Max и перезапустите Max. Остальным модулям он не нужен.

Вопрос

Physics Drop пропускает много объектов

Увеличьте Frames, чтобы куча успела улечься. Убедитесь, что Birth area меньше проёма, и уменьшите Count, если контейнер просто слишком мал.

Вопрос

Куда делся MassFX Tools?

Его заменил Physics Drop, который работает на tyFlow вместо MassFX.

Вопрос

Не могу найти инструмент в категории Nfinite

С версии v2.9 он в категории PHYSICL. Старые кнопки Nfinite по-прежнему открывают текущую версию, но настройте кнопку заново из PHYSICL.

Вопрос

Scatter размещает не все объекты

Позиции ищутся лучами (до 20 попыток). Если поверхность маленькая, а Count большой, многим объектам не хватит места.

Вопрос

Можно ли отменить действия?

Все операции обёрнуты в блок Undo. Используйте Ctrl+Z, кнопку UNDO в Shelf Tool / Book Shelf или RESET в Physics Drop.
