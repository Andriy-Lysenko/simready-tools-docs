Simready Tools

A unified professional environment for scene assembly, interior population, and physics-based placement in 3ds Max. Seven modules cover the entire pipeline — from painting with objects across surfaces to dropping piles of products into containers with real physics.

⚙️ Installation & Launch

How to install and run Simready Tools in 3ds Max

Method 1: Drag & Drop (Quick)

Step 1

Drag the file

Drag the SimreadyTools.ms file directly into the 3ds Max viewport. The script will automatically register as a macroscript.

Step 2

Assign a hotkey or button

Open Customize → Customize User Interface. In the Category dropdown, find PHYSICL, select SimreadyTools, and assign a shortcut key or drag it onto a toolbar.

Method 2: Scripting → Run Script

Step 1

Run the script

Open Scripting → Run Script... and select the SimreadyTools.ms file. This registers the macroscript. Then launch it from the PHYSICL category as in Method 1.

Requirements

tyFlow

Needed for Physics Drop only

The Physics Drop module runs on the free tyFlow plugin. Without it every other module works, and Physics Drop shows a message that tyFlow is not installed.

⚠️ Category changed: Since v2.9 the tool lives in the PHYSICL category (it was Nfinite before). Old toolbar buttons from the Nfinite category still work: they open the current version. Still, drag the button again from PHYSICL, because the old alias will be removed in a future version.

🎨 Object Painter

Interactive painting with 3D assets on surfaces — like a brush, but for objects

1. Paint With — Object Source

Source: Selected / List

Where objects come from

Selected — the brush paints with whatever is selected in the viewport when you press START PAINTING. Best for quick work with 1-2 objects.

List (default) — objects are loaded into the Items table using the [+] button. Allows you to prepare a set in advance and change it without restarting.

Pick: Order / Random

Pick order

Order — objects from the list are dispensed in strict sequence (1→2→3→1→2→3...). Ideal for rhythmic placement (benches, lampposts).

Random — each brush click randomly picks an object from the list. Ideal for organic population (books, decor, debris).

Mode: All / Selected

Active filter

All — the brush uses all objects in the Items list.

Selected — only highlighted rows in the Items table participate in painting. You can change the highlighted rows while painting.

Items: + / - / X / Sel

List management

[+] — add selected objects to the list. [−] — remove selected rows. [X] — clear the entire list. [Sel] — select the listed objects in the viewport for review.

💡 [+] adds whole models, not their parts. For a model inside an AutoLink hierarchy, it takes the node directly under the *_POS helper. For other objects, it takes the topmost parent.

2. Paint On — Target Surfaces

Target: Grid / Scene / List

Where to paint

Grid — objects are placed on the construction grid. Scene — the brush works on any object in the scene. List (default) — painting only on objects from the Surfaces list.

Elem Only

Element mode

The brush paints only on selected polygons. Select the polygons of a shelf surface → enable Elem Only → paint only on that shelf, ignoring the cabinet body and other surfaces. Works with Editable Poly and Editable Mesh, and only with Target: List.

💡 Before enabling Elem Only, select the desired polygons on the target object. The tool makes a temporary red copy of those polygons to paint on and deletes it when you finish.

3. Settings — Brush Parameters

Spacing

Brush step

Minimum distance between objects when painting with a stroke, in scene units. Default 50: objects are placed no closer than 50 units apart along the stroke.

Offset

Normal offset

Raises or sinks the object relative to the surface. Positive values — the object floats above the surface; negative — it penetrates into it.

Follow

Follow stroke direction

The object faces the direction of brush movement. Ideal for placing objects along a path.

Align / Z-Up / Flip

Orientation

Align — align to the surface normal (object follows the slope).

Z-Up (on by default) — force the object to stand upright, even on sloped surfaces.

Flip (Spot) — flip the object upside down (useful for ceiling fixtures).

Auto-Delete Sources

Auto-delete

On by default. When enabled, the original source objects are deleted after painting completes. Keeps the scene clean without duplicates.

Turn 90 (Last)

Quick 90° turn

While painting, rotates the last placed object +90° around its local Z axis. When you are not painting, it rotates the current selection. Click again for another 90°. Can be undone.

4. Randomizer — Chaos & Naturalness

X / Y / Z (Position)

Random offset

Adds random positional offset with each click. The value is the maximum offset in scene units.

Rot X / Rot Y / Rot Z

Random rotation

Enables random rotation around the corresponding axis (0°–360°). Rot Z is the most important button: it rotates the object around the vertical axis, making placement look natural.

💡 For a natural look, enabling only Rot Z is usually enough. Add Rot X/Y only for chaotic scenes (debris, rubble).
Reset Randomizer

Reset

Resets all offsets to zero and turns off all Rot buttons.

5. Progress & Controls

Progress Label

Progress counter

Displays "Placed: N / Total" in real time. When all objects are placed, the message "ALL OBJECTS PLACED!" appears.

START PAINTING

Start/Stop toggle

Toggle button. Press once — the brush is active, click on surfaces to paint. Press again (STOP PAINTING) or hit Escape — painting ends, temporary groups are dissolved, original names are restored.

💡 Painted copies of a source that already sits inside a *_POS hierarchy are moved out to the scene root. That way they don't all pile up under one POS, and you can link them again with Create Hierarchy. Closing the window while painting also cleans up correctly.

📋 Workflow: Object Painter

1. Prepare your assets (product models, decorations, etc.) in the scene.
2. Select Source: List and add models using the [+] button to Items.
3. Select Target: List and add target surfaces (shelves, floor, table).
4. Set Spacing (step distance) and Pick: Random for a natural look.
5. Enable Rot Z in the Randomizer for random rotation.
6. Press START PAINTING and click/stroke across surfaces. Use Turn 90 (Last) if an object lands facing the wrong way.
7. Press STOP PAINTING or Escape to finish.

🔄 Replacer

Batch replacement of proxy objects with final models, preserving position and hierarchy

Replacement Sources — New Models

New Models List

Replacement list

Add the final models that will replace the proxies. Buttons [+] [−] [X] [Sel] — standard list management.

Pick Mode: Random / Order

Selection mode

Random — each proxy is replaced with a random model from the list. Great for varied population.

Order — models are assigned sequentially with wrapping (1→2→3→1→2→3...).

Targets to Replace — Replacement Targets

Existing Models List

Proxies to replace

Add objects that need to be replaced. Each will be deleted with its hierarchy, and a copy of a Source model appears in its place with the same transform and parent. Part names of the copy stay clean (no _001 suffixes).

START REPLACEMENT

Execute replacement

Replaces all targets in one step that you can undo in one go. A summary is shown when it finishes.

💡 Models placed on or inside a target (their own *_POS sub-hierarchies, e.g. boxes on a trolley) are not deleted. They are moved onto the replacement and stay exactly where they were. The summary says how many were kept.

📋 Workflow: Replacer

1. Place simple proxy boxes at the desired positions in the scene.
2. Prepare your final models and add them to Replacement Sources.
3. Select all proxies and add them to Targets to Replace.
4. Choose Random for variety or Order for sequence.
5. Press START REPLACEMENT.

🌿 Scatter

Random distribution of objects across surfaces via raycast

Objects to Scatter — Sources

Items List

Objects to scatter

Add models (grass, rocks, debris, etc.). During scattering, a random object from the list is cloned as an Instance (saving memory).

Surfaces — Target Surfaces

Target Surfaces List

Where to scatter

Surfaces onto which objects will be scattered. Rays are cast straight down inside the combined bounding box of all surfaces; if surfaces overlap, the highest hit is used.

Settings

Count

Number of objects

Target number of objects to place (1–5000, default 50). Each object attempts up to 20 raycast tries to find a valid position.

Z Offset

Height offset

Raises or sinks objects along their local Z (−100 to 100 scene units). Useful for rocks — a small negative value partially buries them.

Align to Normal

Surface normal alignment

On by default. Objects follow the surface slope (for hills). When disabled, objects always stand upright.

Random Z Rot

Random rotation

On by default. Each clone is rotated by a random 0°–360° angle around its Z axis.

Scale Min / Max

Scale range

Random uniform scale in percent (10–500, 100 = original size). Example: Min 80, Max 120 = 80% to 120% of original size.

📋 Workflow: Scatter

1. Create a terrain surface (Plane, landscape mesh).
2. Prepare scatter objects (rocks, bushes) and add them to Items.
3. Add the terrain to Surfaces.
4. Set Count: 200, enable Align to Normal and Random Z Rot.
5. Set Scale Min: 80, Max: 130 for variation.
6. Press START SCATTER. The new objects are selected when it finishes.

📦 Shelf Tool

Automatic product placement on shelves with size calculations, gaps, and interactive Jitter

1. Placement Targets — Shelves

Targets List

Target shelf list

Add one or more shelf objects. The tool processes each shelf sequentially. Supports Editable Poly/Mesh.

Fill All Levels

Auto-detect levels

Scans the cabinet with rays and finds all horizontal surfaces (shelves) inside. Each level is filled separately. When it is off, only the top surface at the centre of the object is filled.

Elem Only

Element mode

Fill only selected polygons. Select the polygons of a specific shelf → objects will only be placed there.

2. Objects to Array — Products

Items List

Objects to array

Add product models. The ▲ / ▼ buttons sort them by footprint (smallest to largest and vice versa).

Pattern: Order / Random

Layout pattern

Order — strict product sequence (A-B-C-A-B-C). Random — random pick for each grid cell.

3. Array Settings — Grid

Cols (X) / Rows (Y)

Columns and rows count

Define the array size (defaults 5 × 1). Cols = across the shelf width, Rows = along the shelf depth.

Calculate X / Y

Auto-calculate

Calculates how many objects fit on the first shelf in Targets, based on the size of the first item in Items and the Gap value.

Depth (Z)

Vertical stacking

Number of layers of objects stacked on top of each other. Depth=2 means two layers.

Gap (cm)

Gap between objects

Spacing between objects, in scene units. Default is 30 (30 mm in a millimetre scene). Increase for loose display, decrease for tight packing.

4. Randomization & Orientation

Pos Jitter / Rot Jitter

Interactive Jitter

Defaults 0.1 and 2°. Applied in real time to the objects from the last fill. Change the values and objects move/rotate instantly. Each object keeps its own random seed, so the same value always gives the same result.

+90° / -90° / 180°

Quick rotation

Rotates every object from the last fill around its own Z axis by 90° or 180°. Use when products face sideways after Fill Shelf.

5. Actions

FILL SHELF

Fill the shelf

Creates an array of clones (Instance) on each target shelf. Objects are centered on the shelf and distributed across the grid. Part names of the clones stay clean. A shelf that is flat to within 0.8° is treated as perfectly flat, so long rows don't slowly rise or sink.

UNDO

Undo fill

Deletes all objects from the last fill operation. If pressed again, triggers the standard 3ds Max Undo.

📋 Workflow: Shelf Tool

1. Select the cabinet/shelf and add it to Targets using the [+] button.
2. Add product models to the Items list.
3. Set Gap and press Calculate X and Calculate Y.
4. Enable Fill All Levels if the whole cabinet should be filled.
5. Press FILL SHELF.
6. If products face sideways, press +90° or -90°.
7. Adjust Pos Jitter and Rot Jitter for a natural look.

📚 Book Shelf

Stand books, binders and organizers upright and fill each shelf compartment, spines facing out

ℹ️ How it differs from Shelf Tool: Shelf Tool lays items out as a grid. Book Shelf builds a single row per compartment. It turns every item upright by itself, measures its real thickness, and packs the items edge-to-edge until the compartment is full. You don't set a column count.

1. Placement Targets — Shelves

Targets List

Target shelves

Add one or more shelf or cabinet objects. Supports Editable Poly/Mesh.

Fill All Levels

Every shelf of the cabinet

Finds all horizontal shelves inside the cabinet and fills each one. The cabinet's outer top is skipped automatically, even when the top panel is a separate mesh of the same model.

Elem Only

Selected polygons only

Fill only the shelves whose polygons are selected on the target object.

2. Objects to Array — Books

Items List

Books to place

Add book, binder or organizer models. ▲ / ▼ sort them by footprint.

Pattern: Order / Random

Sequence

Order — items follow the list in sequence. Random — a random item for each slot.

3. Spacing & Orientation

Gap (cm)

Gap between books

Distance between neighbouring books, in scene units. 0 = packed tight. Default 30.

+90° / -90° / 180°

Quick rotation

Rotates every book from the last fill around its own Z axis.

4. What happens on FILL SHELF

Upright

Automatic orientation

Each book is turned so its tallest side points up, its thinnest side runs along the shelf, and the middle side goes into the depth of the shelf.

Run direction

Along the longer side

The row runs along the longer horizontal side of the shelf. A cabinet rotated 90° still fills along its width.

Spines out

Facing the room

The tool finds the open side of the shelf (away from the back panel) and turns each book so its front/spine edge (where its helper sits) faces out.

Compartments

Respects dividers

Each shelf is split into compartments between side walls and dividers, and each compartment is filled on its own. Books don't pack across a partition.

Seating

Exactly on the board

Every book is centred in the depth of the shelf and set exactly on the shelf surface, so it neither floats nor sinks into it.

UNDO

Undo fill

Deletes all books from the last fill, together with their hierarchies. Pressed again, it runs the standard 3ds Max Undo.

📋 Workflow: Book Shelf

1. Add the bookcase or rack to Targets.
2. Add the book/binder models to Items.
3. Enable Fill All Levels (or select shelf polygons and use Elem Only).
4. Set Gap (0 for a tight row).
5. Press FILL SHELF. Use 180° if a whole fill faces the wrong way.

📊 PolyCount

Scene polygon load audit — quickly find the heaviest models

Parameters

Scope: Selected / Scene

Scan scope

Selected — analyzes only selected objects. Scene — scans all objects in the scene. Switching the scope refreshes the list.

REFRESH LIST

Refresh data

Recalculates polygon counts and sorts the list from heaviest to lightest. Format: "Polycount | Object Name". The list also refreshes when the window opens.

Object List

Interactive selection

Click a row — the object is selected in the viewport. Multi-selection is supported. Use it to quickly navigate to problematic objects.

💡 Tip: Run PolyCount after Scatter/Painter to check if you've overloaded the scene with heavy models. Objects with 50,000+ polygons should be optimized.

💥 Physics Drop

Drop a pile of models into a container or onto a surface with tyFlow physics

⚠️ Replaces MassFX Tools: The old MassFX module has been removed. Physics Drop needs the free tyFlow plugin. It does not add physics modifiers to your models: it simulates simple stand-ins, then places real model copies where the stand-ins came to rest.

1. Models to scatter

Models

What falls

Add the models to drop. Each selected object is resolved to its whole model, so you can click any part of it. Multi-part models fall as one piece.

2. Container / surface

Colliders

What they land in/on

Add the jar, basket, crate, shelf or floor the models should land in or on. If you add a group or helper, the meshes inside it are added.

Birth area

Where objects spawn (optional)

By default, objects spawn above the colliders from an area half the size of the container, centred over it. Pick your own object instead (e.g. a plane tilted to match a sloped shelf) so every object falls the same distance. clear returns to the automatic area.

💡 Make a custom area clearly smaller than the opening (about half). Objects that spawn over the rim roll off and are lost. The tilt itself is fine.

3. Settings

Count

How many

Number of objects to drop (1–2000, default 24). Above 250 you are asked to confirm, because the simulation can take minutes.

Gap

Clearance

Space kept between neighbours (default 3 scene units). The simulated stand-ins are inflated by Gap/2; the final models are not.

Frames

Settle time

How many frames the pile has to settle (30–900, default 120). Raise it if the status line reports many skipped objects.

Seed

Variation

Change it to get a different pile with the same settings.

Helper size

Helper size on placed models

30 for small items (grapes, coffee beans), 50 (default) for medium (tomatoes, cups), 200 for large (watermelons). Too small and the helper hides inside the mesh; too large and neighbouring helpers overlap, so you can't click the one you want.

4. Controls

DROP & BAKE

Run

Builds the simulation, plays it, and places a copy of the matching model at each object that came to rest (geometry as instances, helpers as copies). Objects still moving at the end are skipped. Everything temporary is deleted afterwards, and the timeline and playback settings are restored. Press Esc to stop; nothing is placed.

RESET

Remove last drop

Deletes everything the last DROP & BAKE placed, and only that; earlier drops stay.

Status line

Result

Shows "Placed N, skipped M (time)" after a run.

📋 Workflow: Physics Drop

1. Add the models to Models to scatter.
2. Add the container or surface to Colliders.
3. Optional: pick a custom Birth area for sloped shelves.
4. Set Count, Gap and Helper size.
5. Press DROP & BAKE and wait for the status line.
6. Not happy? RESET, change Seed or Frames, and run again.

📋 Workflow Examples

Typical end-to-end usage scenarios for Simready Tools

🏪 Scenario 1: Populating a Store Shelf

1. Import the cabinet/shelf rack model into the scene.
2. Open Shelf Tool → add the rack to Targets.
3. Import product models → add them to Items.
4. Enable Fill All Levels to fill every shelf.
5. Press Calculate X/Y → FILL SHELF.
6. Rotate products using +90°/-90° if needed.
7. Add Pos Jitter: 0.3 and Rot Jitter: 3 for realism.
8. Use Object Painter (Elem Only) for manual touch-up on individual shelves.

📚 Scenario 2: Filling a Bookcase or Archive Rack

1. Open Book Shelf → add the bookcase to Targets.
2. Add several book/binder models to Items, choose Random.
3. Enable Fill All Levels, set Gap: 0 for a tight row.
4. Press FILL SHELF — every compartment is filled, spines facing out.
5. Remove a few books by hand for a lived-in look.

🍎 Scenario 3: A Pile in a Container (Physics Drop)

1. Place the container (bowl, jar, crate) in the scene.
2. Open Physics Drop → add the fruit/product models to Models.
3. Add the container to Colliders.
4. Set Count and a matching Helper size (30 / 50 / 200).
5. DROP & BAKE. If objects are skipped, raise Frames and try again.

🔄 Scenario 4: Replacing Proxies with Final Models

1. Place simple proxy boxes on shelves using Shelf Tool or Painter.
2. Import high-poly final models.
3. Open Replacer → add final models to Sources.
4. Select all proxy boxes → add them to Targets.
5. Select Random → START REPLACEMENT.
6. Verify the result via PolyCount — make sure the scene isn't overloaded.

❓ FAQ — Frequently Asked Questions

Solutions to common problems

Common Questions

Question

Painter doesn't paint — empty clicks

Make sure Target: List is selected and surfaces are added. If Elem Only is enabled, polygons must be pre-selected on the target object.

Question

Shelf Tool places objects sideways

Press +90° or -90° after FILL SHELF. The rotation is applied instantly to the entire array.

Question

Physics Drop says "tyFlow is not installed"

Install the free tyFlow plugin for your 3ds Max version and restart Max. The other modules don't need it.

Question

Physics Drop skips many objects

Raise Frames so the pile has time to settle. Make sure the Birth area is smaller than the opening, and lower Count if the container is simply too small.

Question

Where is MassFX Tools?

It was replaced by Physics Drop, which uses tyFlow instead of MassFX.

Question

I can't find the tool under Nfinite

Since v2.9 it is in the PHYSICL category. Old Nfinite buttons still open the current version, but set up the button again from PHYSICL.

Question

Scatter doesn't place all objects

Objects find positions via raycast (up to 20 attempts). If the surface is small and Count is large, many may fail to find a spot.

Question

Can I undo actions?

All operations are wrapped in an Undo block. Use Ctrl+Z, the UNDO button in Shelf Tool / Book Shelf, or RESET in Physics Drop.
